# Front End Portfolio

Personal portfolio website built to showcase my experience as a Front End Developer, focused on clean UI, performance, accessibility, and modern front-end practices.

🔗 **Live demo:**  
https://leonardozambao.github.io/portfolio/

---

## ✨ Features

- Responsive layout (mobile-first)
- Dark / Light mode toggle
- Language switch (EN / PT)
- Component-based architecture
- Performance-focused styling
- Accessible semantic HTML
- Deployed with GitHub Pages

---

## 🛠 Tech Stack

- **React**
- **Vite**
- **Tailwind CSS**
- **JavaScript (ES6+)**
- **HTML5 / Semantic Markup**
- **Git & GitHub**

---

## 🌍 Internationalization

The project uses a lightweight custom internationalization system:

- English as default language
- Portuguese as optional language
- Translations centralized in `locales/`
- Content keys referenced from `data/`

This approach keeps the project scalable and easy to maintain.

---

## 📁 Project Structure

```text
src/
```
